# Fiche livreur

Vos livraisons sont sur votre téléphone, à la page `/livreur` du site.

Restaurant : 022 792 16 89

## Au début du service

1. Ouvrir la page sur votre téléphone. Elle demande votre e-mail.
2. Entrer l'e-mail donné au gérant, puis le code à 8 chiffres reçu par e-mail.
   Sans e-mail sur votre téléphone, demander un code au gérant puis toucher « J'ai un code du restaurant ».
3. Vous restez connecté 12 heures. Il faut se reconnecter à chaque service.
4. Toucher « Activer le son et les alertes », puis accepter. La page sonne et vibre à chaque nouvelle livraison.
5. Garder la page ouverte. Téléphone verrouillé ou page fermée, l'alerte peut ne pas arriver.

## Une tournée

Avant de partir, prendre le terminal de carte s'il y a un montant à encaisser.

1. Le comptoir vous donne une ou plusieurs commandes. Elles apparaissent dans l'ordre de passage.
2. Vérifier les sacs avec les numéros.
3. Toucher « Je pars ». Avec plusieurs sacs, « Je pars avec les 2 ». Le client reçoit un e-mail.
4. « Itinéraire » ouvre votre application de navigation.
5. Chez le client, toucher « Livrée ». La livraison disparaît de la liste.

## Ce que je lis sur chaque livraison

- Le rang dans la tournée et l'heure promise au client, en grand.
- L'adresse, l'étage, le nom sur la sonnette, le code d'entrée, la consigne du client.
- Le nombre d'articles. Pas le détail des plats.
- Le paiement. « Payée en ligne, rien à encaisser », ou « À encaisser » avec le montant pour une commande prise au téléphone.
- « Complément à encaisser », avec un montant, quand le client a ajouté un plat après avoir payé.

## Mes questions

| Je me demande | Réponse |
|---|---|
| Le client ne répond pas à la porte. | « Appeler » suivi de son prénom. Sans réponse, « Problème », « Client absent », « Prévenir le restaurant ». |
| J'ai signalé un problème et j'ai d'autres sacs. | Garder le sac et partir à l'arrêt suivant. Les autres clients n'attendent pas. Le restaurant vous appelle en route. |
| J'ai signalé un problème et c'est mon dernier sac. | Attendre sur place l'appel du restaurant, ou l'appeler au 022 792 16 89. |
| Je ne trouve pas l'adresse. | Appeler le client. Sinon « Problème », « Adresse introuvable ». |
| Autre souci (accident, sac renversé). | « Problème », « Autre », écrire un mot, « Prévenir le restaurant ». Puis appeler le restaurant. |
| Je n'ai plus de réseau. | Continuer. Vos gestes partent seuls quand le réseau revient. Ne pas fermer la page. |
| La page dit « annulée, rapportez le sac ». | Rapporter le sac au restaurant, puis toucher « Compris ». |
| La page dit « close, client absent ». | Rapporter le sac, puis toucher « Compris ». |
| La page dit « donnée à un autre livreur ». | Si vous avez le sac, appeler le restaurant. Puis « Compris ». |
| La page demande mon e-mail en route. | Se reconnecter. Vos livraisons sont toujours là. |
| J'ai touché « Livrée » par erreur. | Appeler le restaurant. Vous ne pouvez pas revenir en arrière. |
| Le client veut ajouter quelque chose à la porte. | Il appelle le restaurant. N'encaisser que ce que la page affiche. |
| Le client dit qu'il manque un plat. | Lui dire d'appeler le restaurant. Le signaler au comptoir à votre retour. |
| Dans quel ordre je livre ? | Dans l'ordre affiché. « Plus tôt » et « Plus tard » déplacent un arrêt. Le comptoir peut aussi le changer. |
| Puis-je prendre une commande moi-même ? | Oui. Sous vos livraisons, « À prendre » liste les commandes sans livreur, avec le numéro, la localité, l'heure et le nombre d'articles. Toucher « Je prends ». L'adresse s'affiche alors dans vos livraisons. |
| Laquelle prendre ? | La liste montre aussi des commandes prévues plus tard. Regarder l'heure, puis demander au comptoir si le sac est prêt. |
| Je dois encaisser une commande entière. | À encaisser : espèces ou carte, avec votre terminal. Encaisser le montant affiché. Rapporter l'argent ou le reçu de carte au comptoir, qui note le paiement. |
| Je dois encaisser un complément. | Espèces ou carte, là aussi. Encaisser le montant, puis toucher « Complément encaissé : espèces » ou « Complément encaissé : carte ». |
| Je n'ai pas de téléphone ce soir. | Le dire au comptoir. Il note « Partie » puis « Livrée » sur la tablette. |
| J'ai perdu mon téléphone. | Appeler le restaurant tout de suite. Le gérant coupe votre accès. |
| Le restaurant voit où je suis ? | Non. Il voit seulement l'heure de la dernière mise à jour de votre page. |

## Les données des clients

- Vous voyez seulement vos livraisons en cours. Plus rien une fois livrées.
- Pas de capture d'écran d'une adresse ou d'un code d'entrée.
- Le site garde la trace de chaque geste.
